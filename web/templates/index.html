WHAT IS THIS PROJECT?

This project's main purpose is to basically help those who are currently studying or learning about digital logic design and might find difficulty with finding the solutions to some problems in references and textbooks, so i tried my best to provide you with a tool that solves some of these problems and can even provide the solution steps for some of them, and the code for the core logic is accessible on the GitHub Repository if you want to check it out.

OFFERED TOOLS

Quine-Mcklusky Solver

Helps you find the minimum boolean expression for a function defined by it's Min-Terms and Dont-Cares, and gives the steps to the Grouping Phase, Simplification Phase and Prime Implicant Chart Phase.

Check it Out

Link-Paths Solver

Helps you solve the system (Mealy, Moore or Mixed), giving solutions to all the output variables and providing the steps for each one alongside the abilty to realize an expression using a flip-flop and generating a state-graph for it.

Check it Out

Flip-Flip Realizer

Helps you realize any boolean expression having a state-variable and input-variables using any Flip-Flop of your choice.

Check it Out
